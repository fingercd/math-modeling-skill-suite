# 首次启动响应模板

用于用户只给出竞赛或题号，例如“我要参加高教社杯，请帮我做 A 题”。

```markdown
(全网广泛调研)

我会先停在调研阶段，不会直接锁定模型、写代码或生成最终结论。

当前已确认：
- 竞赛：
- 题号/方向：

请提供或确认：
- 题面全文或截图/PDF
- 附件数据和字段说明
- 官方提交要求或格式要求
- 是否允许检索公开背景资料、历史相似题、算法论文、模型论文、行业实践案例

我会建立或维护这些目录：
- `research/research.md`
- `paper/writer.md`
- `code/code.md`
- `figures/`
- `outputs/`

本轮只做：
- 题目任务拆解
- 数据和约束盘点
- 检索计划
- 初步候选方法清单
- 更新 `research/research.md`
```

如果用户已经提供题面和数据，跳过索要材料，直接写“已收到材料”，然后进入题目拆解和调研计划。
