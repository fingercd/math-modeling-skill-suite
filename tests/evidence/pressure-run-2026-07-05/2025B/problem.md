## 题目背景

碳化硅（SiC）作为一种新兴的第三代半导体材料，以其优越的综合性能表现正在受到越来越多的关注。碳化硅外延层的厚度是外延材料的关键参数之一，对器件性能有重要影响。因此，制定一套科学、准确、可靠的碳化硅外延层厚度测试标准显得尤为重要。

**红外干涉法**是外延层厚度测量的无损伤测量方法。其工作原理：

- 外延层与衬底因掺杂载流子浓度的不同而有不同的折射率
- 红外光入射到外延层后，一部分从外延层表面反射出来，另一部分从衬底表面反射回来（图1）
- 这两束光在一定条件下会产生干涉条纹
- 可根据红外光谱的波长、外延层的折射率和红外光的入入射角等参数确定外延层的厚度

> 通常外延层的折射率不是常数，它与掺杂载流子的浓度、红外光谱的波长等参数有关。

## 三问框架

### 问题 1：单次反射/透射的干涉模型
如果考虑外延层和衬底界面只有一次反射、透射所产生的干涉条纹的情形（图1），建立确定外延层厚度的数学模型。

关键推导：
- 红外光以入射角 $\theta_0$ 入射
- 两束反射光的光程差 $\Delta = 2d\sqrt{n_2(\nu)^2 - \sin^2\theta_0}$
- $d$：外延层厚度；$n_2(\nu)$：波长（频率）依赖折射率
- 干涉条件 $2d\sqrt{n_2^2 - \sin^2\theta_0} = m\lambda$，$m$ 为整数
- 折射率模型（Drude–Sellmeier）：$n_2(\nu)$ 与载流子浓度 $N$ 和频率 $\nu$ 有关

### 问题 2：对 SiC 实测数据求解
基于 Q1 数学模型设计确定外延层厚度的算法。对**附件 1 和附件 2**提供的碳化硅晶圆片的光谱实测数据（10°、15° 入射角）给出计算结果，并分析结果的可靠性。

附件数据规范（已与 Skyler-Luo README 核对）：
- 附件 1：碳化硅数据，10° 入射角（约 1000~5000 行，波数 ν (cm⁻¹)、反射率 R、噪声列）
- 附件 2：碳化硅数据，15° 入射角
- 附件 3：硅数据，10° 入射角
- 附件 4：硅数据，15° 入射角

求解策略：
- 对光谱找极值点 → 拟合干涉级数 m → 反演厚度 d
- 双角度交叉验证 → 给厚度不确定度
- 重抽样/小波去噪可加

### 问题 3：多光束干涉修正
光波可以在外延层界面和衬底界面产生多次反射和透射（图2），从而产生多光束干涉：

1. 推导产生多光束干涉的必要条件
2. 分析多光束干涉对外延层厚度计算精度可能产生的影响
3. 对**附件 3、4**（硅晶圆片）：分析测试结果是否出现多光束干涉，建立硅外延层厚度计算的数学模型和算法，给出计算结果
4. 如果你认为多光束干涉也会出现在碳化硅晶圆片的测试结果（附件 1 和附件 2）中，从而影响到碳化硅外延层厚度计算的精度，请设法消除其影响，并给出消除影响后的计算结果

关键工具：
- 传输矩阵法（Transfer Matrix Method, TMM）
- 全谱拟合（global fitting）相对单峰拟合更鲁棒
- 折射率 Drude 模型：$n^2(\nu) = \varepsilon_\infty - (N e^2) / (\varepsilon_0 m^* \pi c^2 \nu^2)$ 类形式
- Sellmeier 色散：$n^2 = A + B\lambda^2/(\lambda^2 - C^2)$ 或类似形式
