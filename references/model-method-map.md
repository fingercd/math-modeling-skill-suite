# 建模方法映射

本表用于调研后快速收敛路线。优先选择能解释、能复现、能写清楚的模型。

| 问题类型 | 可选方法 | 适合图表 | 风险 |
| --- | --- | --- | --- |
| 预测 | 线性/岭/随机森林/梯度提升/时间序列基线 | 趋势图、残差图、预测对比 | 数据泄漏、只报分数不解释 |
| 分类 | 逻辑回归、SVM、随机森林、轻量 XGBoost | 混淆矩阵、ROC、特征重要性 | 类别不平衡、指标选择错误 |
| 聚类 | KMeans、层次聚类、DBSCAN、GMM | 降维散点、轮廓系数、类别画像 | 聚类数无解释、尺度未标准化 |
| 评价 | 熵权法、层次分析、TOPSIS、灰色关联 | 指标体系图、权重表、排名表 | 权重主观、指标同向化错误 |
| 优化 | 线性规划、整数规划、启发式搜索、模拟退火 | 方案对比表、敏感性曲线 | 约束漏写、不可行未处理 |
| 网络/路径 | 图论、最短路、最大流、社区发现 | 网络图、路径图、节点指标表 | 图构建依据弱 |
| 机理建模 | 微分方程、差分方程、排队论、库存模型 | 状态转移图、参数敏感性 | 参数难估、假设过强 |
| 空间问题 | GIS 距离、空间聚类、插值、热力图 | 地图、热力图、空间分布图 | 坐标系/尺度错误 |
| 仿真 | 蒙特卡洛、离散事件仿真、Agent-based 简化模型 | 分布图、置信区间、场景对比 | 随机种子和重复次数不足 |

## 路线选择原则

1. 先满足题目每问，再追求模型复杂度。
2. 每个模型必须写清输入、输出、假设、目标函数或评价指标。
3. 论文中每个公式必须能对应代码或手算步骤。
4. 每个核心结果必须有表格或图形支撑。
5. 至少保留一个简单基线，用来证明复杂模型有意义。
