# 轻量模型调参提示

## 通用步骤

1. 固定随机种子。
2. 明确评价指标，和题目目标一致。
3. 标准化或归一化需要尺度敏感的特征。
4. 从小网格开始，不做无限搜索。
5. 保存最佳参数、验证分数、失败尝试。
6. 输出可解释图表：指标对比、特征重要性、聚类画像、敏感性曲线。

## 分类

- 基线：逻辑回归、决策树。
- 可调参数：正则强度、树深、最小叶子样本、类别权重。
- 指标：Accuracy 只适合类别均衡；不均衡时优先 F1、Recall、AUC。

## 聚类

- 先标准化特征。
- KMeans 可尝试小范围 `k`，用轮廓系数和业务解释共同决定。
- DBSCAN 调 `eps` 和 `min_samples`，注意噪声点比例。
- 输出每类样本量、中心特征、代表样本。

## 效果不佳时

停止扩大搜索，提示用户：

- 检查数据质量和特征是否有效
- 重新定义评价指标
- 增加领域特征
- 手动缩小参数范围
- 记录当前自动调参结果和失败原因
